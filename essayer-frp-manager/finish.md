# Terminé !

Vous avez démarré un serveur et un client frp, ouvert un port public vers un service local et ajouté une deuxième instance, le tout depuis le panel.

**Installez-le sur votre propre serveur :**

```
curl -O https://raw.githubusercontent.com/Gogowwww/frp-manager/main/docker-compose.yml
docker compose up -d
```

Les autres façons d'installer (script, apt, Docker en mode hôte) sont dans le [guide d'installation](https://frp-manager.org/fr/docs/installation/).

- Site : https://frp-manager.org/fr/
- Code source : https://github.com/Gogowwww/frp-manager
- Démo en ligne sans machine : https://frp-manager.org/demo/
