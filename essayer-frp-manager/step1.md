# Ouvrir le panel

Ouvrez le panel dans un nouvel onglet : **[Ouvrir FRP Manager]({{TRAFFIC_HOST1_8765}})**.

(Il est aussi dans le menu en haut à droite du terminal, sous **Traffic / Ports**, avec le port `8765`.)

Connectez-vous avec **demo** / **frp-manager-demo**.

Vous arrivez sur le **Tableau de bord** : une carte pour le serveur frp (frps) et une pour le client frp (frpc), toutes deux arrêtées. Chaque carte montre son fichier de configuration, son service, l'interrupteur de démarrage automatique et les actions de l'instance.

Jetez un œil aux **Réglages** et aux **Journaux** si vous voulez, puis passez à l'étape suivante.
