# FRP Manager on Killercoda

Interactive scenarios for [FRP Manager](https://frp-manager.org), published on [killercoda.com](https://killercoda.com).
They start the official Docker image on a throwaway machine, so you can try the real panel in your browser.

Scénarios interactifs pour [FRP Manager](https://frp-manager.org/fr/), publiés sur [killercoda.com](https://killercoda.com).
Ils lancent l'image Docker officielle sur une machine jetable, pour essayer le vrai panel dans votre navigateur.

| Scenario | Language |
|---|---|
| `try-frp-manager` | English |
| `essayer-frp-manager` | Français |

Source of the panel: https://github.com/Gogowwww/frp-manager
