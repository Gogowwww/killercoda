# That's it!

You started an frp server and client, opened a public port to a local service and added a second instance, all from the panel.

**Install it on your own server:**

```
curl -O https://raw.githubusercontent.com/Gogowwww/frp-manager/main/docker-compose.yml
docker compose up -d
```

Other ways to install (install script, apt, Docker host mode) are in the [installation guide](https://frp-manager.org/docs/installation/).

- Website: https://frp-manager.org
- Source code: https://github.com/Gogowwww/frp-manager
- Live demo without a machine: https://frp-manager.org/demo/
